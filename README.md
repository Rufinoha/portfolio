## OneSupportBox

**Helpdesk SaaS multitenancy** — painel para equipe de suporte, portal do cliente, chamados omnicanal (portal, e-mail, WhatsApp planejado).

| | |
|---|---|
| **Stack** | Python, Flask, PostgreSQL, Brevo |
| **Planos** | Starter (grátis), Profissional, Empresarial |
| **Status** | Em evolução ativa |

**Funcionalidades em destaque**

- Cadastro self-service de conta (tenant) com ativação por e-mail
- Chamados com protocolo, prioridade, anexos e timeline de interações
- Gestão de clientes, equipe, portais white-label e relatórios
- Academia interna (conteúdo em vídeo para equipe)
